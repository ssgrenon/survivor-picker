# survivor-picker
New Survivor picker utilizing historical data to fine tune algorithm

## Running the app without a terminal

You don't need to know any command-line commands to use the app.

- **Windows:** double-click `run_app.bat`.
- **Mac:** double-click `run_app.command`.

A black/terminal window will open and do some setup (installing or
updating the app's dependencies), then a browser tab with the app will
open automatically once it's ready — this can take a little while the
first time. Leave that window open while you use the app.

To stop the app, just close the terminal window. (Closing the browser
tab alone does not stop it.)

Requires [Python 3](https://www.python.org/downloads/) to already be
installed on your computer. On Windows, make sure to check "Add
python.exe to PATH" during installation.
